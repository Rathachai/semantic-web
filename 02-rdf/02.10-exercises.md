# 02.10 แบบฝึกหัด Chapter 02

แบบฝึกหัดชุดนี้เน้นการ **ลงมือเขียน Turtle จริง** ทั้ง full form และ shorthand แปลงข้ามรูปแบบ
และตรวจผลด้วย rdflib ทุกข้อมีวิธี verify ที่ชัดเจน ให้รันจริงทุกครั้งก่อนถือว่าทำเสร็จ

> ตัวอย่าง data ทั้งหมดให้เขียนเป็น **ภาษาอังกฤษ** และใช้ namespace `http://example.org/`

---

### Exercise 1: เขียน 20 triple เกี่ยวกับตัวคุณเอง

**โจทย์**

เขียนไฟล์ `me-full.ttl` ที่บรรยายตัวคุณเอง **อย่างน้อย 20 triple** ใน **full form** (หนึ่งบรรทัดหนึ่ง triple ไม่ใช้ `;` `,` `[]` `()`)

ต้องครอบคลุมทุกข้อต่อไปนี้:

| ต้องมี | อย่างน้อย |
| --- | --- |
| `rdf:type` | 2 triple (ตัวคุณ + resource อื่น) |
| plain literal | 3 triple |
| language-tagged literal (`@en` และภาษาอื่น) | 2 triple |
| typed literal (`xsd:date`, `xsd:integer`, `xsd:boolean`) | 3 triple |
| object เป็น IRI (link ไปหา resource อื่น) | 4 triple |
| blank node | 1 กลุ่ม (2+ triple) |
| `owl:sameAs` ไปยัง IRI ภายนอกจริง | 1 triple |
| vocabulary ที่มีอยู่จริง (`foaf:`, `schema:`, `dcterms:`) | ใช้อย่างน้อย 2 ตัว |

ตัวอย่างจุดเริ่มต้น:

```turtle
@prefix ex:      <http://example.org/> .
@prefix rdf:     <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs:    <http://www.w3.org/2000/01/rdf-schema#> .
@prefix owl:     <http://www.w3.org/2002/07/owl#> .
@prefix xsd:     <http://www.w3.org/2001/XMLSchema#> .
@prefix foaf:    <http://xmlns.com/foaf/0.1/> .
@prefix schema:  <https://schema.org/> .
@prefix dcterms: <http://purl.org/dc/terms/> .

ex:me rdf:type foaf:Person .
ex:me foaf:name "Somchai Jaidee" .
ex:me rdfs:label "Somchai Jaidee"@en .
ex:me rdfs:label "สมชาย ใจดี"@th .
ex:me schema:birthDate "1995-04-12"^^xsd:date .
# ... เขียนต่อให้ครบ 20 triple
```

**Expected output**

```bash
python -c "
from rdflib import Graph
g = Graph(); g.parse('me-full.ttl', format='turtle')
print(f'{len(g)} triples')
assert len(g) >= 20, 'ต้องมีอย่างน้อย 20 triple'
print('PASS')
"
```

```
23 triples
PASS
```

### Exercise 2: แปลง full form เป็น shorthand

**โจทย์**

1. นำ `me-full.ttl` จาก Exercise 1 มาเขียนใหม่เป็น `me-short.ttl` โดยใช้ shorthand ให้มากที่สุด
   (`;` `,` `[]` `()` `a` และตัวเลข/boolean แบบไม่มีเครื่องหมายคำพูด)
2. เพิ่ม RDF collection อย่างน้อย 1 อันที่ลำดับสำคัญจริง (เช่น รายชื่อภาษาที่พูดได้เรียงตามความคล่อง)
3. **พิสูจน์ว่าทั้งสองไฟล์เป็น graph เดียวกัน** — ยกเว้นส่วนที่เพิ่มในข้อ 2

**Expected output**

```bash
python -c "
from rdflib import Graph
from rdflib.compare import isomorphic

full  = Graph().parse('me-full.ttl',  format='turtle')
short = Graph().parse('me-short.ttl', format='turtle')

print('full  :', len(full),  'triples')
print('short :', len(short), 'triples')
print('isomorphic:', isomorphic(full, short))
"
```

```
full  : 23 triples
short : 29 triples          # +6 จาก collection ที่เพิ่ม (3 items)
isomorphic: False           # เพราะเพิ่ม collection
```

จากนั้นลบ collection ออกจาก short แล้วทดสอบใหม่ ต้องได้ `isomorphic: True`

พร้อมส่งตารางเทียบจำนวนบรรทัด:

| ไฟล์ | บรรทัด | triple | อัตราส่วนบรรทัด/triple |
| --- | --- | --- | --- |
| `me-full.ttl` | 31 | 23 | 1.35 |
| `me-short.ttl` | 18 | 23 | 0.78 |

### Exercise 3: แปลง graph เดียวกันเป็น JSON-LD และ N-Triples

**โจทย์**

จาก `me-short.ttl`:

1. แปลงเป็น **N-Triples** (`me.nt`) — นับจำนวนบรรทัดแล้วเทียบกับ `len(graph)`
2. แปลงเป็น **JSON-LD แบบ expanded** (`me-expanded.jsonld`)
3. แปลงเป็น **JSON-LD แบบ compacted** (`me-compacted.jsonld`) โดยเขียน `@context` เองให้ field ชื่ออ่านง่าย
   (เช่น `"name"` แทน `"foaf:name"`, `"birthDate"` ที่กำหนด `"@type": "xsd:date"` ไว้ใน context)
4. แปลงเป็น **RDF/XML** (`me.rdf`)
5. โหลดทั้ง 4 ไฟล์กลับเข้ามาแล้วพิสูจน์ว่าเป็น graph เดียวกันทั้งหมด
6. เปรียบเทียบ **ขนาดไฟล์** ของทั้ง 5 format แล้วอธิบายว่าทำไมจึงต่างกัน

**Expected output**

```
me-short.ttl        1,204 bytes  (1.00x)
me-compacted.jsonld 1,832 bytes  (1.52x)
me.nt               3,451 bytes  (2.87x)
me-expanded.jsonld  3,910 bytes  (3.25x)
me.rdf              2,678 bytes  (2.22x)

Round-trip check:
  [OK] me.nt               -> 23 triples, isomorphic=True
  [OK] me-expanded.jsonld  -> 23 triples, isomorphic=True
  [OK] me-compacted.jsonld -> 23 triples, isomorphic=True
  [OK] me.rdf              -> 23 triples, isomorphic=True
```

พร้อมย่อหน้าอธิบาย 3–5 บรรทัดว่าทำไม N-Triples ใหญ่ที่สุดเมื่อเทียบกับ Turtle

### Exercise 4: อ่าน Turtle แล้วนับ triple ด้วยตา

**โจทย์**

กำหนดไฟล์ Turtle ต่อไปนี้ **ห้ามรันโปรแกรม** ให้ตอบด้วยการอ่านอย่างเดียวก่อน

```turtle
@prefix ex:  <http://example.org/> .
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .

ex:Paper001 a ex:Article ;
    ex:title  "On the Radiation of Uranium" ;
    ex:author ( ex:MarieCurie ex:PierreCurie ) ;
    ex:keyword "radioactivity" , "uranium" , "physics" ;
    ex:review [ ex:reviewer ex:Reviewer1 ;
                ex:score    5 ] ,
              [ ex:reviewer ex:Reviewer2 ;
                ex:score    4 ] .

ex:MarieCurie ex:wrote ex:Paper001 .
```

ตอบคำถาม:

1. graph นี้มีทั้งหมดกี่ triple (แสดงวิธีนับ)
2. มี blank node กี่ตัว
3. เขียน graph นี้ใหม่เป็น **full form ทั้งหมด** (ใช้ `_:b0`, `_:b1`, … ตั้งชื่อเอง)
4. ทำไม `ex:author` กับ `ex:keyword` จึงให้จำนวน triple ต่างกัน ทั้งที่มี 3 กับ 2 ค่า

**Expected output**

คำตอบข้อ 1 พร้อมการนับแยกส่วน:

```
a ex:Article                     : 1
ex:title                         : 1
ex:author (collection 2 items)   : 1 + 4 = 5
ex:keyword (3 values)            : 3
ex:review (2 bnodes x 2 props)   : 2 + 4 = 6
ex:MarieCurie ex:wrote           : 1
────────────────────────────────────
รวม                              : 17
```

จากนั้นตรวจคำตอบด้วย:

```bash
python -c "
from rdflib import Graph
g = Graph().parse('ex4.ttl', format='turtle')
print(len(g), 'triples')
bnodes = {n for n in g.all_nodes() if n.__class__.__name__ == 'BNode'}
print(len(bnodes), 'blank nodes')
"
```

### Exercise 5: สร้าง graph ด้วย rdflib แล้วเทียบกับ Turtle ที่เขียนมือ

**โจทย์**

1. เขียนไฟล์ `library.ttl` ด้วยมือ บรรยายห้องสมุดเล็ก ๆ:
   - `ex:Library001` เป็น `schema:Library` มีชื่อและที่อยู่ (ใช้ blank node)
   - หนังสือ 3 เล่ม แต่ละเล่มมี `dcterms:title`, `dcterms:creator` (เป็น IRI), `schema:isbn`, `schema:datePublished`
   - ผู้แต่ง 2 คน แต่ละคนมี `foaf:name` และ `owl:sameAs` ไปยัง Wikidata จริง
   - หนังสือทุกเล่มเชื่อมกับห้องสมุดด้วย `ex:heldBy`

2. เขียนสคริปต์ `build_library.py` ที่สร้าง **graph เดียวกันทุกประการ** ด้วย rdflib API
   (`Graph()`, `add()`, `URIRef`, `Literal`, `BNode`, `Namespace`)

3. พิสูจน์ว่าทั้งสองวิธีให้ graph เดียวกัน

4. Serialize graph จากสคริปต์ออกเป็น Turtle แล้วเทียบกับไฟล์ที่เขียนมือ — **อธิบายว่าทำไมข้อความไม่เหมือนกัน แต่ graph เหมือนกัน**

**Expected output**

```bash
python build_library.py
```

```
สร้าง graph จาก rdflib : 24 triples
โหลด library.ttl        : 24 triples
isomorphic              : True

ความต่างของข้อความที่ serialize ออกมา:
  - ลำดับ subject เรียงตามตัวอักษร ไม่ใช่ตามที่เขียน
  - blank node ได้ label ใหม่ (_:Nb1c2...)
  - prefix ที่ไม่ได้ใช้ถูกตัดออก
```

โครงสร้างสคริปต์ที่คาดหวัง:

```python
from rdflib import BNode, Graph, Literal, Namespace
from rdflib.namespace import DCTERMS, FOAF, OWL, RDF, XSD
from rdflib.compare import isomorphic

EX     = Namespace("http://example.org/")
SCHEMA = Namespace("https://schema.org/")

def build() -> Graph:
    g = Graph()
    g.bind("ex", EX)
    g.bind("schema", SCHEMA)
    # ... เขียนต่อ
    return g

if __name__ == "__main__":
    built  = build()
    parsed = Graph().parse("library.ttl", format="turtle")
    print("สร้าง graph จาก rdflib :", len(built), "triples")
    print("โหลด library.ttl        :", len(parsed), "triples")
    print("isomorphic              :", isomorphic(built, parsed))
```

## เกณฑ์ตรวจ

| Exercise | ผ่านเมื่อ |
| --- | --- |
| 1 | ไฟล์ parse ผ่าน, ≥ 20 triple, ครบทุกชนิด node ที่กำหนด |
| 2 | `isomorphic() == True` หลังตัด collection ที่เพิ่มออก |
| 3 | ทั้ง 4 format round-trip แล้ว isomorphic กับต้นฉบับ |
| 4 | ตอบจำนวน triple ถูกต้องโดยไม่ต้องรันโปรแกรม |
| 5 | `isomorphic() == True` และอธิบายเหตุผลความต่างของข้อความได้ |

## Key Points

- Exercise 1–2 ฝึกเขียน Turtle **ทั้งสองรูปแบบ** ซึ่งเป็นทักษะที่ใช้ทุก chapter หลังจากนี้
- Exercise 3 ตอกย้ำว่า **format คือเปลือก** — graph เดียวกันเขียนได้หลายแบบ ขนาดต่างกันแต่ความหมายเท่ากัน
- Exercise 4 ฝึก **นับ triple ด้วยตา** ซึ่งจำเป็นตอน debug ontology จริง โดยเฉพาะเรื่อง collection ที่กิน triple มาก
- Exercise 5 เชื่อม **Turtle ที่เขียนมือ** เข้ากับ **rdflib API** และแสดงว่า serialize แล้วข้อความต่างได้แต่ graph ต้องเท่ากัน
- ใช้ `isomorphic()` เป็นเครื่องมือตรวจมาตรฐานทุกข้อ — อย่าเทียบไฟล์ด้วย `diff`
- เก็บ `library.ttl` ไว้ เพราะจะถูกนำไปขยายเป็น ontology เต็มใน [Chapter 08](../08-owl/08.10-python-owl.md)
