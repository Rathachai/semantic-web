### Exercise 1: SELECT + FILTER บน Wikidata

**โจทย์**

เขียน query บน `https://query.wikidata.org/sparql` ที่หา **นักวิทยาศาสตร์หญิงที่ได้รางวัลโนเบล**
พร้อมชื่อ ปีเกิด สัญชาติ และสาขาที่ได้รางวัล

**Property ที่ต้องใช้**

| Property | ความหมาย |
| --- | --- |
| `wdt:P31 wd:Q5` | instance of human |
| `wdt:P21 wd:Q6581072` | sex or gender = female |
| `wdt:P166` | award received |
| `wdt:P569` | date of birth |
| `wdt:P27` | country of citizenship |
| `wd:Q7191` | Nobel Prize |

**ข้อกำหนด**

1. ใช้ `SERVICE wikibase:label` เพื่อได้ label ภาษาอังกฤษ
2. ใช้ `FILTER` กรองเฉพาะคนที่เกิดหลังปี 1850
3. เรียงตามปีเกิด
4. `LIMIT 20`

**Expected output**

| ?personLabel | ?birthYear | ?countryLabel | ?awardLabel |
| --- | --- | --- | --- |
| Marie Curie | 1867 | Poland | Nobel Prize in Physics |
| Marie Curie | 1867 | Poland | Nobel Prize in Chemistry |
| Irène Joliot-Curie | 1897 | France | Nobel Prize in Chemistry |
| Gerty Cori | 1896 | United States | Nobel Prize in Physiology or Medicine |
| ... | ... | ... | ... |

พร้อมโค้ด Python ที่รันได้:

```bash
python exercise1.py

### Exercise 2: OPTIONAL + aggregate บน Wikidata

**โจทย์**

หา **มหาวิทยาลัย 20 แห่งที่มีศิษย์เก่าใน Wikidata มากที่สุด** พร้อมข้อมูลเพิ่มเติมที่อาจไม่มี

**ข้อกำหนด**

1. ใช้ `wdt:P69` (educated at) นับจำนวนคน
2. ใช้ `OPTIONAL` ดึง `wdt:P571` (inception) และ `wdt:P856` (official website) ที่อาจไม่มี
3. ใช้ `GROUP BY` + `COUNT`
4. ใช้ `HAVING` เอาเฉพาะที่มีศิษย์เก่ามากกว่า 500 คน
5. เรียงจากมากไปน้อย

**Expected output**

| ?universityLabel | ?alumniCount | ?inception | ?website |
| --- | --- | --- | --- |
| Harvard University | 8421 | 1636 | https://www.harvard.edu/ |
| University of Oxford | 6234 | 1096 | https://www.ox.ac.uk/ |
| Yale University | 4102 | 1701 | *(unbound)* |
| ... | ... | ... | ... |

พร้อมตอบคำถาม:

- ถ้าย้าย `OPTIONAL` block ออกมาเป็น pattern ปกติ ผลลัพธ์จะเปลี่ยนอย่างไร และเพราะอะไร
- ทำไม query นี้จึงต้องระวังเรื่อง timeout เป็นพิเศษ

### Exercise 3: Property path บน Wikidata

**โจทย์**

ใช้ **property path** ตอบคำถามต่อไปนี้ (แต่ละข้อต้องใช้ path ต่างกัน)

| # | คำถาม | Property path ที่คาดว่าใช้ |
| --- | --- | --- |
| 1 | หาทุก subclass ของ "vehicle" (`wd:Q42889`) ทุกระดับ | `wdt:P279*` |
| 2 | Bangkok (`wd:Q1861`) อยู่ในหน่วยการปกครองอะไรบ้าง ทุกระดับ | `wdt:P131+` |
| 3 | มีใครบ้างที่เป็นอาจารย์ของอาจารย์ของ Albert Einstein | `^wdt:P1066/^wdt:P1066` |
| 4 | หา entity ที่เป็น instance ของ "university" หรือ subclass ของมัน | `wdt:P31/wdt:P279*` |
| 5 | Marie Curie มีความสัมพันธ์อะไรกับ Pierre Curie บ้าง (property ใดก็ได้) | `!(rdfs:label)` |

- ข้อ 1 และ 4 ต้องมี label ภาษาอังกฤษ

**Expected output** (ตัวอย่างข้อ 2)

```
Bangkok อยู่ใน:
  - Thailand
```

**Expected output** (ตัวอย่างข้อ 4)

```
?item            ?itemLabel
wd:Q49088        Columbia University

... (50 แถว)

### Exercise 4: CONSTRUCT — สร้าง dataset ของคุณเอง

**โจทย์**

ใช้ `CONSTRUCT` ดึงข้อมูลจาก Wikidata แล้วแปลงเป็น **vocabulary ของคุณเอง** ที่ใช้ `schema.org`

**ข้อกำหนด**

1. ดึงข้อมูล **นักวิทยาศาสตร์ที่ได้รางวัลโนเบลสาขาฟิสิกส์ 20 คนแรก**
2. แปลงเป็น graph ที่ใช้:
   - `schema:Person` แทน `wd:Q5`
   - `schema:name` แทน `rdfs:label`
   - `schema:birthDate` แทน `wdt:P569`
   - `schema:nationality` แทน `wdt:P27`
   - `schema:award` แทน `wdt:P166`
3. เก็บ `owl:sameAs` ชี้กลับไปยัง Wikidata entity เดิม
4. บันทึกเป็นไฟล์ `nobel-physics.ttl`
5. โหลดกลับด้วย rdflib แล้วนับ triple + รัน SPARQL ตรวจสอบ

**Expected output**

```turtle
@prefix schema: <https://schema.org/> .
@prefix owl:    <http://www.w3.org/2002/07/owl#> .
@prefix ex:     <http://example.org/nobel/> .
@prefix xsd:    <http://www.w3.org/2001/XMLSchema#> .

ex:Q7186 a schema:Person ;
    schema:name        "Marie Curie" ;
    schema:birthDate   "1867-11-07"^^xsd:date ;
    schema:nationality ex:Q36 ;
    schema:award       ex:Q38104 ;
    owl:sameAs         <http://www.wikidata.org/entity/Q7186> .
...
```

```bash
python -c "
from rdflib import Graph
g = Graph().parse('nobel-physics.ttl', format='turtle')
print(f'{len(g)} triples')
rows = list(g.query('''
  PREFIX schema: <https://schema.org/>
  SELECT (COUNT(DISTINCT ?p) AS ?n) WHERE { ?p a schema:Person }
'''))
print(f'{rows[0][0]} persons')
"
```

```
143 triples
20 persons
```

### Exercise 5: Federated query — เชื่อม DBpedia กับ Wikidata

**โจทย์**

เขียน **federated query สองแบบ** ที่ให้ผลลัพธ์เดียวกัน แล้วเปรียบเทียบ

**แบบ A: ใช้ `SERVICE` keyword**

query ที่รันบน DBpedia endpoint แล้วเรียก Wikidata ผ่าน `SERVICE`

- จาก DBpedia: หานักฟิสิกส์ที่เกิดในเยอรมนี พร้อม `owl:sameAs` ไป Wikidata
- จาก Wikidata: ดึง `wdt:P106` (occupation) และ `wdt:P800` (notable work)
- ใช้ `SERVICE SILENT` เพื่อกัน endpoint ล่ม

**แบบ B: Manual federation**

- query DBpedia แยก → เก็บ Wikidata IRI
- สร้าง `VALUES` block
- query Wikidata **ครั้งเดียว**
- join ใน Python

**สิ่งที่ต้องวัดและรายงาน**

| ตัวชี้วัด | แบบ A (SERVICE) | แบบ B (manual) |
| --- | --- | --- |
| จำนวน HTTP request | ? | ? |
| เวลาที่ใช้ (วินาที) | ? | ? |
| จำนวนแถวที่ได้ | ? | ? |
| สำเร็จหรือ timeout | ? | ? |

**Expected output**

```
====================================================================
  เปรียบเทียบ Federated Query
====================================================================
  แบบ A (SERVICE keyword)
    HTTP requests : 1 (จากมุมมองของเรา)
    เวลา          : 38.2 วินาที
    ผลลัพธ์        : 12 แถว

  แบบ B (manual federation)

        และไม่ต้องพึ่ง federation engine ของ DBpedia
```

พร้อมย่อหน้าอธิบาย 3–5 บรรทัดว่า **เมื่อไหร่ควรใช้แบบ A และเมื่อไหร่ควรใช้แบบ B**

## Key Points

- Exercise 1–3 ฝึกเขียน SPARQL บน **endpoint จริง** ที่มีข้อมูลนับร้อยล้าน — ต่างจากไฟล์ตัวอย่างโดยสิ้นเชิง
- Exercise 2 ตอกย้ำความต่างระหว่าง **`OPTIONAL` กับ pattern ปกติ** ในบริบทข้อมูลจริงที่ไม่ครบ
- Exercise 3 ฝึก **property path ทั้ง 5 รูปแบบ** ซึ่งเป็นเครื่องมือหลักในการ query hierarchy
- Exercise 4 ฝึกใช้ **`CONSTRUCT` เป็นเครื่องมือ ETL** — ดึงจากแหล่งหนึ่งแล้วแปลงเป็น vocabulary ของเรา
- Exercise 5 แสดงด้วยตัวเลขจริงว่า **manual federation มักเร็วกว่า `SERVICE`** หลายเท่า
- Exercise 6 ฝึก **workflow named graph** ที่ใช้จริงในระบบ production: asserted → inferred → production
- เก็บไฟล์ `nobel-physics.ttl` จาก Exercise 4 ไว้ เพราะจะใช้ต่อใน [Chapter 07](../07-python-semantic-web/07.12-exercises.md)
